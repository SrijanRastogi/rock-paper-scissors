# Rock Paper Scissors

A browser-based Rock Paper Scissors game built as part of The Odin Project Foundations course.

## Features

- Play Rock Paper Scissors using buttons
- Computer makes a random choice
- Running score tracking
- First player to reach 5 points wins
- Reset button
- Responsive layout for mobile devices
- Results displayed directly on the webpage

## Technologies Used

- HTML
- CSS
- JavaScript
- Git
- GitHub

## How to Run

Open `index.html` in your browser and click the Rock, Paper, or Scissors buttons to play.
