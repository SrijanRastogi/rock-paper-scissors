# Rock Paper Scissors

A console-based implementation of the classic **Rock Paper Scissors** game built as part of **The Odin Project** Foundations.

## About

This version contains **my original solution** to the project. The game is played entirely through the browser's console and uses `prompt()` to collect the player's choice.

The computer randomly selects between **Rock**, **Paper**, and **Scissors**, and the game is played over five rounds before declaring the overall winner.

## Features

* Random computer choice
* User input using `prompt()`
* Five-round gameplay
* Running score tracking
* Final game winner announcement
* Input converted to lowercase for case-insensitive comparisons

## Technologies Used

* HTML
* JavaScript
* Git
* GitHub

## How to Run

1. Clone the repository.
2. Open `index.html` in your browser.
3. Open the browser's Developer Console.
4. Play the game through the prompt dialogs and view the results in the console.
